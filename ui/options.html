Unblock – Options

Custom Rules

One per line. Examples: ##.ad-banner, example.com | .ad-banner, ||ads.example.com, /ads/*.js. Prefix a selector with a domain to scope it.

Whitelisted Domains

Remote Filter Lists

Opt-in. Fetches a filter list over HTTPS and compiles its MV3-safe subset into dynamic rules. The list is cached locally; requests are cookie-less and go only to the list host.

Advanced Features

  • Scriptlets: Lightweight anti-adblock mitigations.
  • Element Picker: Click elements to block visually.
  • Procedural Cosmetic: Live mutation-based hiding.
  • Extended Rulesets: Ads, privacy & trackers (MV3-safe).

Notes

  • MV3 uses static declarativeNetRequest rules. Dynamic filtering is not fully portable to Chromium MV3.
  • Scriptlets run at document_start for earlier coverage.
